# 백엔드 서버 실행 안내

앱의 음성 전사와 자연어 가계부 분석은 PC에서 돌리는 Python 서버(FastAPI)가 처리합니다. 앱을 테스트하려면 먼저 이 서버를 켜 두어야 합니다.

## 준비물

- Python 3.11 이상 (설치할 때 "Add python.exe to PATH"를 체크하세요)
- Gemini API 키
- Android Studio 에뮬레이터, 또는 USB 디버깅을 켠 안드로이드 폰
- `mobile/local.properties`에 Supabase 주소와 키 설정 완료

## 1. 최초 1회 설정

저장소 루트 폴더(`backend` 폴더가 바로 보이는 곳)에서 PowerShell을 엽니다. 탐색기에서 그 폴더를 열고 주소창에 `powershell`을 입력하면 편합니다.

```
if (-not (Test-Path backend\.env)) { Copy-Item backend\.env.example backend\.env }
notepad backend\.env
py -3.11 -m venv backend\.venv
backend\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
```

메모장이 열리면 `GEMINI_API_KEY=` 뒤에 발급받은 키를 붙여 넣고 저장합니다. 모델 이름은 기본값 그대로 두면 됩니다.

`.env` 파일에는 비밀 키가 들어 있으니 GitHub에 올리지 마세요.

## 2. 서버 켜기 (테스트할 때마다)

```
cd backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --reload --port 8000
```

`Application startup complete`라는 문구가 나오면 켜진 것입니다. 이 PowerShell 창을 닫거나 `Ctrl+C`를 누르면 서버가 꺼지므로, 테스트하는 동안은 열어 두세요.

## 3. 서버가 켜졌는지 확인

- 브라우저에서 `http://localhost:8000/health`를 열어 `{"status":"ok"}`가 나오면 정상입니다.
- `http://localhost:8000/docs`에서 `POST /api/v1/ledger/parse`를 골라 `Try it out`을 누르고, `{"transcript": "아아 4500원 마셨어"}`처럼 넣어 보면 앱 없이도 문장 분석을 시험할 수 있습니다.

## 4. 앱에서 서버에 연결하기

**에뮬레이터**: 기본 주소가 `http://10.0.2.2:8000`(에뮬레이터에서 본 내 PC)이라 따로 설정할 것이 없습니다.

**실제 폰**:

1. 폰과 PC를 같은 Wi-Fi에 연결합니다.
2. PowerShell에서 `ipconfig`를 실행해 IPv4 주소(예: 192.168.0.12)를 확인합니다.
3. `C:\Users\내이름\.gradle\gradle.properties` 파일에 아래 줄을 추가합니다. 파일이 없으면 새로 만드세요.

```
transcriptionApiBaseUrl=http://192.168.0.12:8000
```

4. Android Studio에서 Gradle 동기화를 하고 앱을 다시 빌드해서 실행합니다.
5. Windows 방화벽이 포트 8000 접속을 막으면 허용해 줍니다.

## 5. 테스트 순서

1. 서버를 켠다. (2번)
2. Android Studio에서 `app`을 Run 한다.
3. 로그인한다.
4. 기록 탭에서 "아아 4500원이랑 점심 만원"처럼 입력하고 분석 결과가 뜨는지 확인한다.
5. 결과를 저장하고, 분석 탭에서 지난달·또래 비교 화면이 나오는지 확인한다.

## 문제가 생기면

| 증상 | 확인할 것 |
| --- | --- |
| 앱에서 "가계부 항목을 추출하지 못했어요" 메시지 | 서버를 켠 PowerShell 창의 오류 로그를 확인합니다. 대부분 API 키 오류, 모델 이름 오류, 네트워크 문제입니다. |
| 앱이 서버에 연결되지 않음 | 서버가 켜져 있는지, 에뮬레이터는 `10.0.2.2`, 폰은 PC의 IP와 방화벽 설정이 맞는지 확인합니다. |
| `py` 명령을 찾을 수 없음 | Python을 다시 설치하면서 PATH 체크박스를 켜거나, `py` 대신 `python`을 써 봅니다. |
| 포트 8000이 이미 사용 중 | 이전에 켜 둔 서버 창이 남아 있는지 확인하고 닫습니다. |
| `.env`를 고쳤는데 반영이 안 됨 | `Ctrl+C`로 서버를 끄고 2번 명령을 다시 실행합니다. |
